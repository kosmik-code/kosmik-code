# Hi, I'm Kosmik

I stream as **Kosmik** and build small tools for streamers: local, free, and running on your own PC. No accounts, no cloud, nothing to host.

## Projects

- **[kosmik-voice](https://github.com/kosmik-code/kosmik-voice)** · Discord voice overlay for OBS. Reactive images or fixed slots per person, five themes (Pixel café, Clean, Neón, Cómic, Glass), aliases, and a live editor in Spanish or English. Talks to your Discord client through local RPC; no bot joins the call.

## Built with

JavaScript · Node.js · OBS browser sources · Discord RPC
