# Hi, I'm Kosmik

I stream as **Kosmik** and build small tools for streamers: local, free, and running on your own PC. No accounts, no cloud, nothing to host.

## Projects

- **[Kosmik Voice](https://github.com/kosmik-code/kosmik-voice)** · Discord voice overlay for OBS. Reactive images or fixed slots per person, five themes (Pixel café, Clean, Neón, Cómic, Glass), aliases, and a live editor in Spanish or English. Talks to your Discord client through local RPC; no bot joins the call. Lives in the tray and updates itself.

- **[Kosmik Layouts](https://github.com/kosmik-code/kosmik-layouts)** · Per-game OBS layouts in one scene. Open a game and your camera, chat and alerts slide to where you placed them for it, and your game capture points at it; close it and you're back to your "just chatting" layout. No scene switching, no hotkeys, and it never creates, deletes or renames anything in OBS.

Both share the same look (Studio, Daylight, Pixel) and work together: set the Kosmik Voice overlay to **Free box** and each layout can place it somewhere else.

## Built with

Rust · JavaScript · Node.js · OBS browser sources · OBS WebSocket · Discord RPC
